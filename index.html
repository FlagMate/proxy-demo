See how ProxyCeptor SDK reshapes your REST API — live.

Drop one script tag into any web or Smart TV app, connect your workspace API key, and the SDK rewrites, mocks, merges, blocks, or delays your real API calls — all driven by rules you manage in the cloud. No redeploys. Toggle rules here and watch requests change in real time.

1

Add the SDK to your app

One line. The SDK patches fetch, XMLHttpRequest, and sendBeacon — and never breaks your app if a rule fails. 

<script src="https://proxyceptor.com/proxyceptor-sdk.js"></script>
<script>
  ProxyCeptor.init({
    apiKey: 'sdm_live_your_key_here',
    refreshInterval: 300000  // live-sync cloud rules (300s)
  });
</script>
